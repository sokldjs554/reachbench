# 실험 명세

## 작업과 범위

고정 상부 RGB 카메라가 본 붉은 원형 목표의 XY 위치로 로봇팔 끝점을 접근시킨다. 청색 원통 장애물과 로봇 링크의 충돌을 피해야 한다. 성공 조건: 최종 평면 오차 ≤35 mm, 실행된 모든 샘플에서 PyBullet 충돌 없음, 실제 실행 경로 존재. 미검출·도달 불가·경로 차단은 실패로 집계한다.

2개 회전 관절의 **기구학 경로 실행**이다. 로봇 링크 높이는 0.16 m이며 목표 위로 XY를 맞춘다. 목표와 물리적으로 접촉하거나 집지 않는다. 각 자세를 `resetJointState`로 설정한 뒤 `getClosestPoints`로 접촉을 확인한다. 속도/토크 제어·마찰·동역학·관절 추종 오차·안전 인증이 없다. 자기충돌 및 연속시간 충돌 보장은 구현하지 않았다.

## 데이터→인식→계획→평가

1. Scene(seed, condition)가 실제 목표·장애물과 이미지 변형 조건을 생성한다.
2. PyBullet DIRECT + CPU TinyRenderer가 320×320 RGB를 렌더링한다. segmentation ID와 depth는 인식에 사용하지 않는다.
3. 기준 인식은 R>150, G<105, B<105로 목표를, B>125, R<100, G<155로 장애물을 분할한다.
4. 개선 인식은 OpenCV HSV의 빨강 H∈[0,12]∪[170,179], S≥110,V≥30; 파랑 H∈[95,125],S≥100,V≥25를 분할한다. 3×3 opening, 외곽선 면적 ≥7 px², 최소 외접원. 가장 큰 붉은 영역을 목표로 선택한다. 마스크 정제는 실제 수행하지만 학습은 하지 않는다.
5. 알려진 카메라와 높이로 픽셀 중심을 세계 좌표로 역투영한다. 청색 원통은 옆면까지 분할되므로 상면 가정과 외접원은 위치·반경에 편향을 만든다. 이 한계는 정답으로 보정하지 않는다.
6. IK로 가능한 목표 관절각을 구한다. 기준 방법은 시작점에서 가까운 IK 해까지 직접 관절 보간한다. 개선은 65×65 관절 격자, 8방향 이웃, 유클리드 관절 거리 휴리스틱 A*, 두 IK 후보, 경로 단축을 사용한다.
7. 계획 단계는 링크 선분과 추정 장애물의 거리에서 링크 반폭 25 mm 및 여유 12 mm를 고려한다. 연결 구간을 나누어 검사하며, 계획기의 샘플 간 최대 관절 변화는 0.05 rad 미만이다. 실행 단계는 더 촘촘한 0.025 rad 이하를 사용한다. **계획기에는 추정 목표·장애물만 전달한다.** 알려진 로봇 치수·시작각·관절 한계는 사용한다.
8. 실행은 최대 관절 변화 0.025 rad로 보간하며, 각 샘플의 충돌은 PyBullet의 실제 도형으로 독립 판정한다. 명목 샘플 간격 0.05초. 실제 목표 좌표는 마지막 위치 오차 계산에만 사용한다.

## 기하 설정

- 베이스 (-0.5,0) m, 링크 길이 0.55/0.45 m, 반폭 0.025 m
- 시작 관절각 (-1.1,1.5) rad, 각 관절 ±2.7 rad
- 카메라 (0,0,2.6) m, z축 아래를 바라봄, +Y가 영상 위, 수직 FOV=47°, 주점 (160,160)
- f=320/(2 tan(47°/2)); X=(u−160)(2.6−z)/f; Y=(160−v)(2.6−z)/f
- 목표 높이 0.022 m, 반경 0.035 m; 장애물 높이 0.36 m
- XY 추정에는 각 객체의 높이를 알고 있다고 가정한다. 일반 물체·미지 높이에 적용되는 3D 추정기가 아니다.
- FK: p1=base+l1[cos q1,sin q1], p2=p1+l2[cos(q1+q2),sin(q1+q2)]

## 실험 프로토콜

개발용 seed 0–9와 100으로 실행 여부를 확인했다. 처음 개발한 장애물 범위가 첫 링크 회전을 막는 장면을 많이 만들었으므로, 손끝 경로 선택을 비교하는 문제에 맞춰 장애물 X 범위를 조정했다. 이는 평가 전 설계 변경이다. 이후 `sim.py`를 고정하고 seed 1000–1019를 다섯 조건에서 전수 평가했다. 결과를 본 뒤 장면을 삭제하거나 성공 사례만 재선정하지 않았다. 이 분포는 장애물 회피가 필요한 작은 작업을 의도적으로 구성했으며 일반 현장 분포를 대표하지 않는다.

| 항목 | 범위 |
|---|---|
| 목표 | X~U(0.10,0.32), Y~U(0.22,0.46) m |
| 주 장애물 | X~U(0.20,0.35), Y~U(-0.06,0.12), 반경~U(0.045,0.075) m |
| 기본 | 밝기 1.0, 잡음 없음 |
| 어두운 조명 | 렌더링 후 RGB×0.38 + N(0,5²), [0,255] clip |
| 추가 장애물 | (-0.22,0.34), 반경 0.07 m 원통 추가 |
| 목표 가림 | 초기 RGB의 목표 투영점 주위 25×25 회색 패치. 3D 가림 물체는 아님 |
| 보정 오차 | 모든 픽셀→세계 X 변환에 +0.065 m 편향 |

조건 내 같은 seed와 네 방법은 같은 장면/입력을 공유한다. 조건 간에도 seed를 재사용해 비교 가능하게 했다. 이미지 잡음 seed는 scene seed+100000이다. 조명·잡음은 테스트 스트레스이며 학습 증강의 효과를 평가한 것이 아니다. 데이터 정제는 작은 영역 제거·형태학 처리와 기록 무결성 검사에 해당한다. 실패 기록도 남기며 학습 데이터 품질을 검증했다고 주장하지 않는다.

## 해석 시 유의점

- 학습·사전학습 가중치·공개 데이터셋 사용 없음. 결과는 규칙 기반 인식과 기하 계획의 비교다.
- 위치 인식 평균 오차는 검출된 장면만 포함한다. 미검출이 많은 기준 방법과 숫자만 비교하면 왜곡된다.
- 최종 오차는 정지한 실패 장면까지 포함한다. 성공 장면만의 정밀도와 다르다.
- 처리 시간은 perf_counter 1회/실행. 인식·계획만 포함하고 렌더링·파일 I/O·실행은 제외한다. 계획 미실행은 0 ms로 기록된다. 비전용 CPU에서 조건별 순차 실행했으므로 하드웨어 벤치마크나 엄격한 속도 비교로 쓰지 않는다.
- Wilson 95% 구간은 에피소드의 이항 근사이며 같은 seed를 재사용한 조건 간 상관을 보정하지 않는다. 실물 성능의 추론 구간이 아니다.
- A*의 목표 차단/no_path는 이 격자·보수적 추정·여유 거리에서 못 찾았다는 뜻이다. 연속 공간에서 경로가 없다는 증명은 아니다.
- 카메라 보정에 잘못된 확신이 있으면 계획기까지 같은 방향으로 틀릴 수 있다. 12 mm 여유로 65 mm 보정 오류를 흡수할 수 없다. 따라서 개선 방법도 충돌한다.
