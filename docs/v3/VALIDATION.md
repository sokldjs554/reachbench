- `npm run check`: 세 신규 JavaScript 모듈 문법 확인.
- `npm run test:ui`: **4개 Node 테스트 통과** 및 보존한 기존 UI의 DOM/데이터 검증 통과. DOM 검증을 실제 브라우저 검증으로 계산하지 않는다.

- 재생/일시정지/초기화/시간 탐색, 0초 실패 기록, 마지막 성공 단계, 라이브 복귀, seed 전환, 모바일 같은 장면 비교를 확인했다.
- 모델 파일 요청을 강제로 차단한 경우에도 저장된 실제 센서 이미지·이벤트·결과를 열 수 있음을 확인했다.
- 공식 관리형 미리보기는 relay 4173 연결 시간 초과로 실행되지 않았다. 로컬 HTTP와 headless Chromium으로 대체했다. 실제 iPhone/Android 기기, Safari/Firefox, 화면 낭독기, 저성능 기기 장시간 안정성은 확인하지 않았다.
- 브라우저 검증의 빠른 완료 단계는 실제 WASM physics step을 배치 호출한다. 이 테스트 소요 시간을 사용자 기기의 실시간 FPS/제어 지연으로 보고하지 않는다.
- 모델을 고정 Python/npm 버전에서 다시 빌드했고 평가 설정의 Python 소스·MJCF SHA-256이 현재 소스와 일치했다. 기존 `dist/data`, `dist/data-v2`, `dist/media`, `reachbench/`는 v2 기준 커밋과 변경 없음.

## 독립 코드 검토 후 수정

새 검토자가 정책 입력/정답 경계, 물리 집기, 짝 평가를 확인했다. 모델 로딩 실패 시 기록 접근, 새 MuJoCo 의존성, 정지 사례의 높이 지표, 기록 재생 최종 단계 문제를 수정했다. 실제 한 번의 재시도 성공 `shifted-107-feedback`도 공개 사례로 추가했다. 기존 160회 중 이 사례만으로 전체 개선을 계산하지 않는다.

## 공개 배포 검증

배포 후 동일 검증을 공개 URL에서 수행한 결과는 `public-validation.json`에 보존한다. 라이브 결과의 벽시계 시간에는 자동화 환경과 렌더링 부하가 포함되며 성능 벤치마크가 아니다.
