# RGB-D 기록의 크기와 유효 깊이 검사

`manipulation/check_rgbd.py`는 NPZ 파일의 RGB/depth 이미지 형식과 크기를 검사하고 유효 깊이 픽셀 비율을 출력한다. 센서 기록을 분석하기 전 확인하는 작은 데이터 검사 도구다.

## 실행

저장소 루트에서 NumPy가 설치된 Python 환경을 사용한다.

```bash
.venv/bin/python -m manipulation.check_rgbd dist/bench/runs/shifted-107-feedback/camera-1.npz
```

보관된 seed 107 기록의 결과:

```text
이미지 크기 (너비 x 높이): 224 x 224
유효 깊이 비율: 87.09%
```

50,176개 중 43,700개 픽셀이 조건을 만족한다. 자신의 기록을 검사하려면 경로 인자만 바꾼다. 다른 장면의 비율이 이 값과 같아야 하는 것은 아니다.

## 검사 범위

- NPZ에 `rgb`, `depth` 배열이 있어야 한다.
- RGB는 `(H, W, 3)`, depth는 `(H, W)`이고 두 이미지 크기가 같아야 한다.
- 픽셀이 없는 이미지는 거부한다.
- 유효 깊이는 `isfinite(depth) & (depth > 0) & (depth < 3)`이다. 입력 깊이 단위는 m로 가정한다.
- 유효 비율은 이미지 전체 픽셀을 분모로 계산한다. 검출된 목표 마스크 안의 비율이나 인식 정확도가 아니다.
- 배경이나 거리 제한 때문에 일부 픽셀이 제외될 수 있다. 유효 비율이 0%인 비어 있지 않은 이미지도 비율을 출력하며, 비율만으로 파일 오류를 판정하지 않는다.

이 검사는 RGB 색공간·자료형, 카메라 보정, 시각·행동 정렬, 좌표 변환 정확도까지 보장하지 않는다. 3 m는 이 프로젝트의 인식 코드와 맞춘 처리 범위이며 실제 센서의 보편적인 유효 거리 기준이 아니다.

## 자동 검증

```bash
.venv/bin/python -m pytest -q tests/test_rgbd_validation.py
```

2026-11-19, Python 3.11.18 / NumPy 2.2.6에서 8개 테스트 통과.

| 입력 | 기대 결과 |
|---|---|
| 깊이 `[[0.5, 1.0, 2.0, 2.9], [0.0, 3.0, NaN, Inf]]`, RGB `(2, 4, 3)` | 50.00% |
| depth `(2, 4)`, RGB `(2, 2, 3)` | 크기 불일치 `ValueError`, 비율 출력 없음 |
| RGB 차원·채널 수 또는 depth 차원 오류, 3종 | 형식 `ValueError` |
| 높이 0인 빈 이미지 | 빈 이미지 `ValueError` |
| 모든 픽셀 유효 / 모든 픽셀 무효, 2종 | 각각 100.00% / 0.00% |

정상 비율 검사와 크기 불일치 검사는 별도 테스트다. 후자는 예상한 예외를 명시적으로 확인하므로 예외가 발생했을 때 테스트가 통과하고, 잘못된 입력을 받아들이면 실패한다. 테스트 배열은 임시 디렉터리에 저장하며 실제 관측 파일을 수정하지 않는다.
